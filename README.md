# Water-Pollution-Analysis-and-Water-Quality-Assessment-using-SQL
Developed a comprehensive SQL-based data analysis project to evaluate water quality across multiple monitoring stations in India. Performed data cleaning, pollution assessment, trend analysis, and environmental reporting using SQL queries, CTEs, views, and aggregate functions. Created a custom Pollution Index to identify pollution hotspots and generate state-wise and year-wise water quality insights.

# Overview
This SQL project focuses on analyzing water quality and pollution trends across different monitoring stations and states in India. 
The project uses environmental parameters such as temperature, pH, conductivity, Biological Oxygen Demand (BOD), nitrate concentration, fecal coliform, and total coliform levels to assess water quality, identify pollution hotspots, and generate meaningful environmental insights.

# Key Objectives:

Design and manage a water pollution database using SQL.

Perform data cleaning, validation, and quality checks.

Analyze temperature and water quality trends across states and years.

Identify highly polluted and clean water monitoring stations.

Calculate a custom Pollution Index using multiple pollution indicators.

Categorize water bodies based on pH levels and pollution severity.

Create reusable SQL views for reporting and analysis.

Generate state-wise and year-wise environmental performance reports.

# Major Tasks Performed

Created and structured a relational database for water quality monitoring data.

Conducted null value checks and data validation.

Analyzed annual temperature variations and climate patterns.

Identified stations with extreme temperature fluctuations.

Evaluated nitrate hotspots and high-conductivity regions.

Developed pollution ranking models using BOD, nitrate, and coliform parameters.

Categorized water quality as Acidic, Neutral, or Alkaline based on pH values.

Created SQL Views for automated reporting and pollution analysis.

Generated state-wise and year-wise pollution trend reports.
