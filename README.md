# Water-Pollution-Analysis-and-Water-Quality-Assessment-using-SQL
This SQL project focuses on analyzing water quality and pollution trends across different monitoring stations and states in India. 
The project uses environmental parameters such as temperature, pH, conductivity, Biological Oxygen Demand (BOD), nitrate concentration, fecal coliform, and total coliform levels to assess water quality, identify pollution hotspots, and generate meaningful environmental insights.

# Key Objectives:

Design and manage a water pollution database using SQL.
Perform data cleaning, validation, and quality checks.
Analyze temperature and water quality trends across states and years.
Identify highly polluted and clean water monitoring stations.
Calculate a custom Pollution Index using multiple pollution indicators.
Categorize water bodies based on pH levels and pollution severity.
Create reusable SQL views for reporting and analysis.
Generate state-wise and year-wise environmental performance reports.
